Ninar Studio

A private production tool for calm YouTube content: sleep sounds, music for babies and children's songs.

What it is

Ninar Studio is a command-line tool written and operated by a single independent creator. It runs only on the creator's own computer and is not offered to the public.

It renders videos locally, checks their quality (duration, format, loudness, silence, metadata limits and asset licenses) and uploads the finished videos to the creator's own YouTube channels. Every video is uploaded as private and reviewed by hand in YouTube Studio before being published.

YouTube API Services

Ninar Studio uses YouTube API Services (YouTube Data API v3) only to upload videos and set their thumbnails on channels owned by its operator. It does not read analytics, comments, subscribers or any other user's data.

By using Ninar Studio you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.
